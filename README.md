# carlosrellan.github.io

Source code of the personal academic website of Carlos Rodríguez Rellán (University of Granada): <https://carlosrellan.github.io>

The site is built with [Hugo](https://gohugo.io) and [Hugo Blox Builder](https://hugoblox.com) (Academic CV template) and is deployed to GitHub Pages by GitHub Actions (`.github/workflows/publish.yaml`) on every push to `main`.

## Local preview

```bash
hugo server
```
